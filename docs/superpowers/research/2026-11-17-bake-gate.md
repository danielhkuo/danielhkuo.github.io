# Bake gate (task 0) — 2026-11-17

**Verdict: PASS in Chrome by a wide margin; Safari pending the owner.**

## Method
- Bench: `src/world/bench/bake-bench.ts` does the design's real per-cell workload (5.5) for one 256 × 256 chunk: B-spline upsample, gradients, 7 field samples, the 10-rule cover table with blue-noise jitter, crown scatter stamping, 16-cell relief blur, Lambert light, diagonal shadow sweep, front-to-back painter over 520 world rows, occlusion ink, dither and hatch. Reviewed by Claude: honest, slightly pessimistic (a tile lookup per painted cell).
- Page: `/world-bench` in the static export (`npm run build`), served from `out/` by `scripts/world-bench.mjs`, Puppeteer's headless Chrome 148.
- Warm runs fly north through a column and step east each lap, so every chunk meets fresh land and reuses only its southern tiles (~1.25 new tiles per chunk), as in flight.
- **Throttling cannot reach workers.** Chrome answers `Emulation.setCPUThrottlingRate` on a worker target with "Operation is only supported for pages, not workers", so page throttling leaves the bake untouched. The laptop proxy below scales measured times by 4 instead, as the design's "4× CPU throttle".

## Notes

- Background tab: not measured (headless Chrome does not hide a backgrounded page reliably).
